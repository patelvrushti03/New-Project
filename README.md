# First Project

This is a Django-based web application. It has basic user authentication and profile management features.

# Features

- User Registration 
- User Login
- User Logout 
- Forgot Password
- Profile Management

# Tech Stack

- Python 
- Django 
- HTML 
- CSS 

# About Project

This project is a simple authentication system. Users can create an account, log in, log out, and manage their profile. This project is made for learning Django basics.
